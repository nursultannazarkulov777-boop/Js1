Код — это просто

Схема с доски, разобранная по шагам: от старта программы до вывода информации.

  1. Start
  2. Router v1v2v3
  3. const / let / var ↔ Number / String …
  4. Info

Start: с чего всё начинается

Программа запускается и ждёт запросы. Например, кто-то открывает адрес в браузере. Дальше запрос попадает к маршрутизатору.

Router: куда отправить запрос

Router смотрит на адрес и решает, какой код запустить. Так же, как указатель на вокзале: «на этот путь — туда».

Версии v1, v2, v3 — это разные варианты одного сервиса. Старые приложения работают через v1, новые — через v3, и ничего не ломается.

app.use("/v1", routerV1);
app.use("/v2", routerV2);
app.use("/v3", routerV3);

Переменные и типы

Переменная — коробка с именем. Тип — что лежит внутри. Они связаны: у каждой переменной есть значение, а у значения есть тип.

const
Значение нельзя заменить. Бери по умолчанию.
let
Значение можно менять позже.
var
Старый способ. В новом коде не нужен.
Number
Числа: 7, 3.14.
String
Текст в кавычках: "привет".
…
Есть и другие типы: Boolean (да/нет), Array (список), Object.
const user = "Аня";   // String
let score = 0;        // Number
score = score + 1;

Info: смотрим, что получилось

И переменные, и типы ведут к одному — к информации, которую можно вывести командой console.log(). Введи значение и узнай его тип.
